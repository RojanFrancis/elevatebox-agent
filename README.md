# ElevateBox AI Voice Agent 🤖📞

An intelligent outbound voice calling agent built for ElevateBox that autonomously conducts sales calls, classifies leads using AI, and sends contextual WhatsApp follow-ups — all from a single REST trigger.

## 🎯 What It Does

1. **Triggers an outbound AI voice call** via Vapi to a prospect
2. **AI agent conducts the conversation** — asks qualifying questions, handles objections
3. **Gemini AI classifies the lead** as `HOT`, `WARM`, or `COLD` from the transcript
4. **Sends WhatsApp messages** mid-call (brochures, info) and post-call (personalised follow-up)
5. **Notifies the sales team** with a full call report

## ⚡ Quick Start

### Prerequisites
- Java 21
- Maven
- Vapi account + credits
- Google Gemini API key
- Meta WhatsApp Cloud API (free)

### Setup

1. **Clone the repo**
```bash
git clone https://github.com/RojanFrancis/elevatebox-agent.git
cd elevatebox-agent/agent
```

2. **Configure API keys** in `src/main/resources/application.yml`
```yaml
vapi:
  private-key: YOUR_VAPI_KEY

gemini:
  api-key: YOUR_GEMINI_KEY

meta:
  whatsapp:
    phone-number-id: YOUR_PHONE_NUMBER_ID
    token: YOUR_META_TOKEN
```

3. **Build and run**
```bash
mvn clean install
mvn spring-boot:run
```

4. **Test health check**
```bash
curl http://localhost:8081/api/call/health
# {"status":"UP","service":"ElevateBox AI Agent"}
```

5. **Test lead classification**
```bash
curl -X POST http://localhost:8081/api/call/classify \
  -H "Content-Type: application/json" \
  -d '{"transcript": "Yes I am very interested, what is the pricing? I want to start this week."}'
# {"classification":"HOT"}
```

6. **Trigger a real call** (requires ngrok for webhook)
```bash
# Terminal 1 — expose webhook
ngrok http 8081

# Terminal 2 — trigger call
curl -X POST http://localhost:8081/api/call/initiate
```

## 🧠 Lead Classification Logic

Gemini AI classifies each call as:

| Classification | Criteria |
|---------------|----------|
| 🔥 **HOT** | Strong interest, budget confirmed, wants to move forward this week |
| 🌡️ **WARM** | Interested but needs nurturing, has objections, open to follow-up |
| ❄️ **COLD** | Not interested, wrong timing, asked not to be contacted |

## 📱 WhatsApp Flow

- **Pre-call** — Heads-up message before the call
- **Mid-call** — Triggered by keywords ("send me info") during live call
- **Post-call** — Personalised follow-up generated by Gemini based on transcript
- **Sales team** — Internal notification with full call report + classification
